# Ingeniería Inversa – Paso 1: Análisis de Logs

Actúa como un **Ingeniero de Software Senior**, **Arquitecto de Software**, **Especialista DevOps** y **Analista de Ingeniería Inversa**.

## Objetivo

Analizar completamente el proyecto CAFE-IA desde la perspectiva de los registros de ejecución (logs), sin modificar ningún archivo del proyecto.

## Instrucciones

1. Analiza los logs generados durante la ejecución del proyecto.
2. Revisa:

   * Backend
   * Frontend
   * Build
   * Railway
   * Vercel
   * MySQL
   * npm
   * Prisma
   * Cypress
   * JMeter
   * SonarQube
3. Identifica:

   * Errores
   * Advertencias
   * Excepciones
   * Problemas de configuración
   * Dependencias faltantes
   * Variables de entorno incorrectas
   * Problemas de autenticación
   * Problemas de conexión
   * Problemas de despliegue
4. Clasifica cada hallazgo como:

   * Crítico
   * Alto
   * Medio
   * Bajo
5. Genera una matriz con:

   * ID
   * Hallazgo
   * Evidencia
   * Causa
   * Impacto
   * Recomendación
   * Prioridad
6. Al finalizar redacta un resumen ejecutivo indicando:

   * Estado general del proyecto.
   * Riesgos encontrados.
   * Principales problemas.
   * Recomendaciones.
7. No modifiques ningún archivo.
8. No corrijas el código.
9. Solo realiza el análisis técnico y documenta los resultados.

## Resultado esperado

Generar un informe técnico de análisis de logs que servirá como base para continuar con la Ingeniería Inversa del proyecto CAFE-IA.
